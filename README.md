# 피즐리 (Pizzly)

> 틈새시간을 웰니스 시간으로 바꿔주는 AI 캐릭터 서비스

## 이게 뭔가요

피즐리는 엘리베이터를 기다리거나, 버스를 기다리거나, 잠깐 짬이 나는 **틈새시간**에 AI 캐릭터 "피즐리"가
지금 이 순간에 딱 맞는 미니 웰니스 퀘스트를 추천해주는 서비스입니다.

사용자가 지금 쓸 수 있는 시간(1분/3분/5분), 현재 상황(앉아있음/서있음/이동 중/조용한 장소),
현재 컨디션(눈 피로/손목·손가락/목·어깨/휴식)을 선택하면, 그에 맞는 짧은 웰니스 퀘스트를 추천받습니다.
퀘스트를 수행하고 완료하면 경험치와 랜덤 보상을 얻고, 그 보상으로 캐릭터 피즐리가 성장합니다.

퀘스트는 아래 4개 영역을 다룹니다.
- 눈 건강
- 손목 관리
- 목·어깨 관리
- 호흡·휴식

## 왜 만드나요

하루 종일 책상 앞이나 이동 중에 눈, 손목, 목, 어깨가 지쳐가는데도, 따로 시간을 내서 스트레칭이나
휴식을 챙기기는 쉽지 않습니다. "따로 시간 내기"가 진입 장벽이라고 보고, 피즐리는 이미 비어 있는
틈새시간(엘리베이터 대기, 버스 대기 등)에 자연스럽게 끼어들어 아주 짧은 웰니스 습관을 만들어주는
것을 목표로 합니다. 캐릭터를 키우는 재미 요소를 더해서, 웰니스 습관 자체가 지속 가능하도록 설계했습니다.

## 형태

홈 화면에 설치해서 앱처럼 쓸 수 있는 **PWA**입니다. 오프라인에서도 기본 화면은 동작합니다.

## 팀

6명 — 백엔드 2명(BE1, BE2), 프론트엔드 2명(FE1, FE2), 기획 1명(PM), 디자인 1명(DS)

각자 담당 영역과 상세 역할 분담은 [개발 계획 노션 페이지](https://app.notion.com/p/3b7be414a288811fa42cce622d640e6e)를 참고하세요.

## 기술 스택 (요약)

프론트엔드는 React + TypeScript + Vite + Tailwind CSS, 백엔드는 Node.js + Express + TypeScript +
MySQL(Prisma)로 만들고 있습니다. `apps/web`(프론트)과 `apps/api`(백엔드)로 구성된 모노레포입니다.

코드를 작성하거나 수정할 때 지켜야 하는 세부 규칙(네이밍, API 응답 포맷, Git 규칙, 폴더 구조 등)은
[CLAUDE.md](./CLAUDE.md)에 따로 정리되어 있습니다.

## 시작하기

```bash
npm install
cp .env.example .env   # 값 채워넣기
```
