# 피즐리 (Pizzly)

틈새시간(엘리베이터, 버스 대기 등)에 AI 캐릭터 피즐리가 눈 건강 / 손목 관리 / 목·어깨 관리 / 호흡·휴식
4개 영역의 미니 웰니스 퀘스트를 추천해주는 서비스입니다. (2026 멋쟁이사자처럼 중앙해커톤 AAC 트랙 출품작)

## 구조
모노레포(`apps/web`, `apps/api`)입니다. 자세한 규칙은 [CLAUDE.md](./CLAUDE.md) 참고.

## 시작하기
```bash
npm install
cp .env.example .env   # 값 채워넣기
```
